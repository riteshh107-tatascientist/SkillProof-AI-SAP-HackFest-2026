# 7-minute demo script (SAP officers + faculty)
1. **Home (30s):** problem - pedigree and keywords hide capable people. Point to the event bar and the "AI assists, humans decide" strip. State: independent project, SAP integration is proposed only.
2. **Sign in as Demo Candidate -> Candidate Studio (60s):** *Use sample resume* -> *Analyse*. Show suggested skills with evidence; untick one, add evidence, tick the confirmation box, **Save**.
3. **Resume Analyzer (40s):** quality score, checklist, keyword gap for Data Analyst.
4. **Job Matching (60s):** pick Data Analyst -> gauge, matched/missing, transferable skills, "Why this score?". Say: overlap, not hire probability. Download the CSV report.
5. **Career Roadmap (40s):** 30/60/90 plan, tick a task (progress saved).
6. **Sign out -> Demo Recruiter -> Recruiter Hub (70s):** blind comparison, evidence review, record a human decision with rationale, open Audit history.
7. **Fairness Lab (60s):** synthetic legacy screen vs skills-based screen by institution tier; show impact ratio, small-sample warning, "signal not proof".
8. **AI Assistant (30s):** ask a question in Gemini/OpenAI (or Demo - say it is rule-based). Mention PII redaction + consent.
9. **About (30s):** architecture; proposed SuccessFactors / BTP / Analytics Cloud / Joule; limitations.
**Likely questions:** "How accurate?" -> metrics only on synthetic labels, caveated; plan is labelled real data. "Bias?" -> no protected attrs in matching; audit lab; human approval. "Why not just an LLM?" -> explainable, evidence-linked, auditable.
